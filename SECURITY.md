# Security Policy

## Purpose

Security is a core consideration of the Tanzania Digital Sovereignty Framework.
This repository may discuss cybersecurity architecture, digital infrastructure,
blockchain systems, identity, data governance, and public-sector technology.

## Reporting a Vulnerability

Please do not publish exploitable vulnerability details in public issues.

Use GitHub's private vulnerability reporting feature, if enabled for this
repository, or contact the repository owner through a private GitHub channel.

When reporting, include:

- A clear description of the issue.
- Affected files, components, or versions.
- Steps to reproduce, where safe and appropriate.
- Potential impact.
- Suggested mitigation, if known.

Do not include real credentials, personal data, classified information,
or sensitive production-system details.

## Response

The maintainers will review reports as resources permit and may request
additional information. No specific response or remediation time is guaranteed.

## Responsible Disclosure

Please allow maintainers a reasonable opportunity to assess and address
a reported issue before publicly disclosing technical details.

## Scope and Disclaimer

This repository is a strategic and technical framework. It is not, by itself,
a production security certification, penetration-test report, or guarantee
that any implementation is secure.

Security-sensitive implementations require independent professional review.
