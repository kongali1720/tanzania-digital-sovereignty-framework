# Support

Thank you for your interest in the Tanzania Digital Sovereignty Framework.

## How to Get Help

For questions and project assistance:

- Open a GitHub issue for documentation questions or reproducible problems.
- Use GitHub Discussions if enabled for general project discussions.
- Submit a pull request for corrections and improvements.
- Review the README and other documentation before opening a new issue.

## Supporting the Project

You can support continued development by:

- Improving technical and policy documentation.
- Reviewing research and references.
- Reporting documentation errors.
- Sharing constructive feedback.
- Contributing code, diagrams, and analysis.
- Supporting development through the PayPal link in the README.
